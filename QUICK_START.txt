🎯 KEY INNOVATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. TWO-TIER ARCHITECTURE
   T1 (Recent) + T2 (Frequent) = Best of LRU + LFU

2. ADAPTIVE LEARNING
   Ghost lists B1, B2 track evictions
   Algorithm learns and adapts to workload patterns

3. VALUE-BASED SCORING
   score = frequency^1.2 × (1 / recency^0.5)
   Intelligent eviction decisions

4. SMART PROMOTION
   T1 → T2 on second access
   Ghost hits → directly to T2
   Prevents cache pollution

5. O(1) COMPLEXITY
   All operations are constant time
   Production-ready performance

💡 ALGORITHM EXPLANATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: Traditional algorithms have limitations
• FIFO: Doesn't consider access patterns
• LRU:  Good for recency, bad for frequency
• LFU:  Good for frequency, suffers cache pollution

SOLUTION: Adaptive-ARC combines all strengths
• Two-tier structure (T1 for recent, T2 for frequent)
• Ghost lists learn from eviction mistakes
• Adaptive parameter balances recency vs frequency
• Value scoring considers both dimensions
• O(1) operations using OrderedDict

RESULT: Best average performance across all workload types!

🔍 TECHNICAL DETAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Data Structures:
  T1: OrderedDict()  # Recent items (recency-focused)
  T2: OrderedDict()  # Frequent items (frequency-focused)
  B1: OrderedDict()  # Ghost entries from T1
  B2: OrderedDict()  # Ghost entries from T2
  p:  int            # Adaptive partition parameter

Time Complexity:
  get():      O(1)   # Hash lookup + move_to_end
  put():      O(1)   # Insert with possible eviction
  _adapt():   O(1)   # Simple arithmetic
  _replace(): O(1)   # Amortized

Space Complexity:
  O(capacity) for main cache (T1 + T2)
  O(capacity) for ghost lists (B1 + B2)
  Total: O(capacity) - linear in cache size
